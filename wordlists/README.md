# Local Word Lists

This directory is reserved for vocabulary files supplied by the user. No third-party word list is distributed with the repository or required by ResearchLoop.

Only import material that you created, that is in the public domain, or that you are otherwise authorized to use. Local CSV files should remain untracked and must not be included in the event demo database.

The simplest CSV format is:

```csv
word,meaning,example,tags
```

Open `/words/import`, paste the authorized content, preview duplicate or invalid rows, and confirm the import.
